# Interactive Product Inventory & Analytics Dashboard

## EWB EduTech Internship Capstone Project

### Project Overview
Stockwise is an interactive web-based dashboard for managing product inventory and analyzing stock data. It allows users to add and remove products, search and filter inventory, calculate discounts and taxes, and view inventory analytics.

### Features
- Add and remove products
- Product validation and duplicate checking
- Search, filter, and sort inventory
- Product categories: Budget, Standard, and Premium
- Total inventory value, product count, and average price
- Affordable product analysis
- Tax and discount calculator
- Formatted inventory report
- Export inventory data as CSV
- Local storage to retain inventory data in the browser

### Technologies Used
- HTML5
- CSS3
- JavaScript

### How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add products and explore the dashboard features.
